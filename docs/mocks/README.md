# Mock screens

Design mocks for the demo loop. Sign-in and invites are deliberately left out:
everyone in the mocks already has the extension.

- [`interactions.md`](interactions.md): every interaction in the loop, in
  order, with the defaults chosen for the demo.
- [`slides.html`](slides.html): pitch slides plus one slide per screen. Open it
  in a browser; arrow keys move, `A` shows every slide on one page.
- [`storyboard.html`](storyboard.html): the same screens on one scrolling page.

All three are self-contained; no build step.
