# Mock screens

Design mocks for the demo loop. Sign-in and invites are deliberately left out:
everyone in the mocks already has the extension.

- [`interactions.md`](interactions.md): every interaction in the loop, in
  order, with the defaults chosen for the demo.
- [`../storyboard/`](../storyboard/index.html): every screen on one scrolling
  page. Live at https://boweiliu.github.io/manifest-yt-recs/storyboard/
- [`../slides/`](../slides/index.html): pitch slides plus one slide per screen.
  Arrow keys move, `A` shows every slide on one page. Live at
  https://boweiliu.github.io/manifest-yt-recs/slides/
